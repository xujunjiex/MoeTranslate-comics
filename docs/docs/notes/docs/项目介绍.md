## 简介

Android 翻译应用，基于 Android 11+ 的无障碍截图权限开发，支持**游戏翻译**和**漫画翻译**两大功能。

支持两种翻译模式：

- **本地 OCR + 文本翻译：** 通过 PP-OCRv5 / ML Kit 实现本地 OCR 识别（支持中文、日文、英文、韩文），然后调用翻译 API 获取结果。

- **图片翻译：** 将截图直接上传给 API 翻译，适用于其他语言。

## 一、游戏翻译

截图 OCR + 翻译 API，支持多种翻译引擎：

- ML Kit / NLLB（离线翻译）
- 必应翻译、小牛翻译、OpenAI 兼容接口
- 火山引擎、Azure、DeepL、百度翻译、腾讯云
- 自定义 API

## 二、漫画翻译

漫画/游戏气泡文字翻译，支持：

- **检测引擎：** PP-OCRv5 det、CTD、RT-DETR-V2、ML Kit
- **OCR 引擎：** PP-OCRv5 rec（中/日/英/韩）、manga-ocr（竖排日文）、ML Kit
- **翻译：** 复用游戏翻译的所有 API
- **渲染：** 半透明背景 + 竖排/横排文字覆盖
