# 星译（StarFlow）

免费开源的 Android 翻译工具，支持游戏翻译和漫画翻译。

---

## 简介

星译是一个安卓手机上的翻译应用，专门为游戏玩家和漫画读者设计。

- **漫画翻译：** 自动检测气泡区域，识别文字，翻译后竖排显示在原位置
- **游戏翻译：** 截图 OCR 识别文字，翻译结果直接覆盖在游戏画面上

免费，开源，没有广告，没有 VIP。支持 Android 11 以上，仅支持 arm64-v8a。

---

## 漫画翻译

打开日文漫画，点一下悬浮球，几秒钟搞定。

### 翻译流程

截图 → 检测气泡区域 → OCR 识别文字 → 翻译 → 竖排文字覆盖在原位置

全自动，翻到新的一页，点一下就能翻译。

### 检测引擎

| 引擎 | 说明 | 是否需要下载 |
|------|------|-------------|
| **PP-OCRv5**（默认） | 独立 det+cls+rec 全流水线 | 内置，开箱即用 |
| **ML Kit** | ML Kit 检测+识别一体化 | 内置 |
| **CTD** | CTD 检测 + 指定 OCR 引擎 | 需下载（~94MB） |
| **RT-DETR-V2** | 气泡/文字检测 | 需下载（~11MB） |

### OCR 引擎

| 引擎 | 说明 | 是否需要下载 |
|------|------|-------------|
| **PP-OCRv5**（默认） | 中日英混合识别 | 内置 |
| **ML Kit** | Google ML Kit 识别 | 内置 |
| **manga-ocr** | 竖排日文专用识别 | 需下载（~135MB） |

### 普通/高级模式

- **普通模式**（默认）：引擎自动循环切换（MLKit → PP-OCRv5 → manga-ocr → MLKit），不可用的引擎自动跳过，不用折腾
- **高级模式**：自由搭配检测器和识别器，菜单分两个选项独立选择

### 语言支持

- **中文/日文：** 始终可用（内置 PP-OCRv5 rec_zh 模型，支持中日英混合识别）
- **英文：** 内置 rec_zh 也支持英文；可下载专用 rec_en 模型（~7.5MB）获得更好效果
- **韩文：** 需下载 rec_ko 模型（~12.9MB）
- **俄文：** 需下载 rec_ru 模型（~7.7MB）

### 自动翻译

开启后，连续翻页会自动检测页面变化，停稳后约 1 秒自动触发翻译。

- 翻页时自动检测页面是否稳定（基于 pHash 相似度）
- 稳定后自动触发翻译，不用反复点
- 想立即翻译，点击悬浮球跳过等待
- 翻过的页面有缓存，再次打开秒显示（左上角显示 ⚡ 标识）
- 点击刷新按钮可强制重新翻译

### 增量渲染

气泡超过 6 个的页面，自动分批处理：

- 首批翻译完立即渲染，不用等全部翻完
- 第二批翻译完成后最终渲染
- 两批之间使用上下文，让第二批能看到第一批的译文
- 气泡多的页面体验提升明显

### 翻译结果

- 竖排文字覆盖在气泡原位置
- 自动选择合适的字号
- 支持对话和旁白两种文字样式

## 游戏翻译

打开日文游戏，点悬浮球，翻译结果直接盖在游戏画面上。

### 翻译流程

截图 → OCR 识别文字 → 翻译 → 结果覆盖在游戏画面上

### 两种翻译模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **文字翻译** | 先 OCR 识别截图中的文字，再调用翻译 API | 大部分场景 |
| **图片翻译** | 直接把截图发给图片翻译 API，API 自己识别并翻译 | OCR 难以识别的语言 |

### 翻译结果容器

- 可以拖动到任意位置
- 可以锁定固定位置（锁定后不可拖动）
- 可以关闭后重新翻译
- 支持框选区域，只翻译画面的一部分

### 自动翻译（像素驱动）

开启后，应用自动检测画面变化，变化稳定后自动触发翻译。

**状态机：**
```
IDLE（跳过OCR）──像素变化──→ CHANGED ──稳定1帧──→ STABLE_1 ──稳定2帧──→ STABLE_2（触发OCR）→ IDLE
```

- IDLE：翻译完成后进入，像素不变则跳过 OCR（节省性能）
- 稳定性检测可关闭：关闭后像素变化立即触发 OCR（适合视频字幕）

**像素比较：** YIQ 感知色彩差异（移植自 pixelmatch），阈值可调（默认 1%）

**LRU 缓存：** OCR 文本精确匹配，命中直接返回翻译结果，不重复调用 API

**设置项：**
- 像素变化阈值（默认 1%）
- 检测间隔（最低 300ms）
- 翻页稳定性检测开关

### OCR 引擎

| 引擎 | 说明 |
|------|------|
| **MLKit**（默认） | Google ML Kit，速度快 |
| **PP-OCRv5** | 内置引擎，中日英混合识别 |
| **manga-ocr** | 竖排日文专用，精度高 |

### 悬浮球手势

三个手势（单击、双击、长按）可分别配置不同动作：

| 动作 | 说明 |
|------|------|
| 翻译 | 点击触发翻译 |
| 菜单 | 打开功能菜单 |
| 自动翻译 | 开关自动翻译 |

选择时自动互换冲突项，不会重复。

### 框选翻译

支持框选屏幕区域，只翻译框选范围内的文字。

- 框选初始位置：屏幕中央
- 框选可自由调整大小和位置
- 框选区域底部有确认按钮，跟随框选实时移动

### 调试浮窗

关于页面可开启，显示：
- 当前状态（IDLE/CHANGED/STABLE）
- 像素差异百分比
- OCR 和翻译耗时
- 点击展开日志面板（最近 20 条，自动去重）

## 翻译 API

免费的能用，付费的更强，随便选。

### 免费 API

| API | 说明 |
|-----|------|
| **必应翻译** | 免费，不需要注册 |
| **ML Kit** | Google 离线翻译，不需要网络 |
| **NLLB** | Meta 本地翻译，完全离线，适合不想泄露内容的场景 |

### 云端 API

| API | 说明 |
|-----|------|
| **DeepL** | 翻译质量高 |
| **百度翻译** | 国内稳定 |
| **腾讯翻译** | 国内稳定 |
| **Azure** | 微软翻译 |

### AI 翻译

支持所有 OpenAI 兼容接口：

| API | 说明 |
|-----|------|
| **DeepSeek** | 国产 AI，性价比高 |
| **火山引擎** | 字节跳动 |
| **智谱AI** | GLM 系列 |
| **通义千问** | 阿里巴巴 |
| **自建 API** | 填入你自己的 OpenAI 兼容 API 地址 |

### AI 上下文

开启后，翻译会结合之前的对话剧情。比如角色说了"那个东西"，上下文能让 AI 知道"那个东西"指的是什么，翻译更准确。

- 游戏模式：可配置保留 1 到 10 轮历史对话
- 漫画模式：增量渲染的两批之间自动使用上下文

### 自定义提示词

对 OpenAI 兼容 API 生效，游戏和漫画的提示词独立配置：

- 游戏提示词：配置游戏翻译时的系统提示词
- 漫画提示词：配置漫画翻译时的系统提示词
- 每个 API 可以单独配置不同的提示词

---

## 翻译缓存

翻译结果自动缓存，相同内容不重复调用 API。

- **游戏模式：** OCR 文本精确匹配，命中直接返回缓存结果
- **漫画模式：** pHash 精确匹配 + 相似度匹配（阈值 0.92），翻过的页面秒显示
- 缓存命中时显示 ⚡ 标识
- 漫画模式左上角有刷新按钮，可强制重新翻译

---

## 翻译历史

所有翻译记录自动保存，按会话分组。

- 游戏翻译按时间排列
- 漫画翻译可以全屏翻页浏览原图，底部显示译文详情
- 每次启动生成独立会话 ID，历史记录按会话分组
- 支持查看原文和译文对比

## 模型管理

### 内置模型（开箱即用）

| 模型 | 用途 | 大小 |
|------|------|------|
| PP-OCRv5 det | 文字区域检测 | ~4.6MB |
| PP-OCRv5 cls | 方向分类 | ~1MB |
| PP-OCRv5 rec zh | 中日英混合识别 | ~16MB |

核心模型内置在应用中，约 22MB，不需要额外下载。

### 可选模型（按需下载）

| 模型 | 用途 | 大小 |
|------|------|------|
| PP-OCRv5 rec en | 英文专用识别 | ~7.5MB |
| PP-OCRv5 rec ko | 韩文专用识别 | ~12.9MB |
| PP-OCRv5 rec ru | 俄文/西里尔文字识别 | ~7.7MB |
| CTD | 文字区域检测 | ~94MB |
| RT-DETR-V2 | 气泡/文字检测 | ~11MB |
| manga-ocr | 竖排日文识别 | ~135MB |

可选模型从模型管理页面下载，支持断点续传，不用担心网络中断。

## 个性化设置

### 悬浮球手势

单击、双击、长按三个手势可分别配置翻译、菜单、自动翻译，互斥不重复。

### 语言切换

源语言和目标语言随时切换：
- 中文、日文、英文、韩文、俄文等
- 翻译运行中会锁定语言切换，避免翻译结果错乱

### 其他设置

- 悬浮球大小和透明度
- 翻译结果字体大小
- 自动翻译参数（像素阈值、检测间隔等）
- AI 上下文轮数
- 增量渲染开关

## 安全

- **API 密钥加密存储：** 使用 Android Keystore 加密，即使手机被 root 也看不到明文
- **禁止明文传输：** 所有网络请求强制 HTTPS，不允许 HTTP
- **翻译数据不进系统备份：** Room 数据库排除在 Android Auto Backup 之外

## 首次使用

首次启动有引导页面：

1. 配置无障碍服务权限（游戏翻译需要）
2. 配置悬浮窗权限
3. 选择翻译 API 并配置密钥（如需要）

引导完成后即可使用。
