# 星译（StarFlow）完整软件介绍 — 视频脚本

## 视频信息

- **标题：** 星译 — 一款支持游戏翻译和漫画翻译的 Android 应用
- **时长：** 约 5 分钟
- **风格：** 实机演示 + 字幕解说，节奏紧凑，每个功能 3-5 秒画面

---

## 一、开头（15s）

**画面：** App 图标 → 启动画面 → 主界面

**字幕/旁白：**
> 星译是一款 Android 翻译应用，专门为游戏玩家和漫画读者设计。
> 支持游戏实时翻译和漫画翻译，OCR 识别 + AI 翻译 + 悬浮窗覆盖显示。
> 支持 Android 11 以上，完全免费开源。

---

## 二、游戏翻译（90s）

### 2.1 基础流程（30s）

**演示：** 打开一个日文游戏 → 点击悬浮球 → 翻译结果显示在游戏画面上

**字幕/旁白：**
> 游戏翻译的核心是悬浮球。打开游戏后，点击悬浮球就会自动截图、OCR 识别文字、调用翻译 API，翻译结果直接覆盖在游戏画面上。
>
> 翻译结果可以拖动到任意位置，也可以锁定固定位置，或者关闭后重新翻译。
>
> 还支持框选功能 — 只选择画面的一部分进行翻译，不遮挡其他内容。

**重点展示：**
- 悬浮球在游戏画面上的位置
- 点击后翻译结果出现的过程
- 结果容器的拖动、锁定、关闭操作
- 框选翻译区域

### 2.2 两种翻译模式（15s）

**演示：** 切换到文字翻译模式 → 翻译一次 → 切换到图片翻译模式 → 翻译一次

**字幕/旁白：**
> 星译支持两种翻译模式。
>
> 文字翻译模式：先用 OCR 识别截图中的文字，再调用翻译 API 翻译文字。适合大部分场景。
>
> 图片翻译模式：直接把截图发给图片翻译 API，API 自己识别文字并翻译。适合 OCR 难以识别的语言。

**重点展示：**
- 设置页面切换翻译模式
- 两种模式翻译同一画面的效果对比

### 2.3 自动翻译（20s）

**演示：** 开启自动翻译 → 翻页 → 自动翻译触发 → 翻页 → 再次触发

**字幕/旁白：**
> 开启自动翻译后，不用每次手动点击。应用会自动检测画面变化 — 翻页、切换场景时自动触发翻译。
>
> 相同的文字不会重复翻译，直接返回缓存结果，速度快且省流量。
>
> 对于视频字幕，可以关闭翻页稳定性检测，画面变化立即翻译。

**重点展示：**
- 开启自动翻译的按钮位置
- 翻页后自动翻译的过程（注意等待时间）
- 缓存命中时的 ⚡ 标识

### 2.4 翻译 API 选择（15s）

**演示：** 设置页面展示 API 列表 → 切换不同 API → 翻译同一段文字

**字幕/旁白：**
> 星译支持 10 多种翻译 API。
>
> 免费的有必应翻译、ML Kit 和 NLLB 本地翻译。
> 云端有 DeepL、百度、腾讯、Azure 等。
> AI 翻译支持所有 OpenAI 兼容接口 — 火山、智谱、DeepSeek、通义千问，或者填入你自己的 API 地址。
>
> 本地翻译完全离线，不需要网络，适合不想泄露内容的场景。

**重点展示：**
- API 列表页面
- 不同 API 翻译同一段文字的效果对比
- 自建 API 的配置页面

### 2.5 AI 上下文翻译（10s）

**演示：** 关闭上下文翻译一次 → 开启上下文翻译一次 → 对比效果

**字幕/旁白：**
> 开启 AI 上下文后，翻译会结合之前的对话剧情。比如角色说了"那个东西"，上下文能让 AI 知道"那个东西"指的是什么，翻译更准确。
>
> 可以设置保留 1 到 10 轮历史对话。

**重点展示：**
- 上下文开关位置
- 同一段对话开启前后的翻译对比

## 三、漫画翻译（80s）

### 3.1 基础流程（20s）

**演示：** 打开漫画 App → 点击漫画翻译悬浮球 → 截图 → 气泡检测 → 翻译 → 竖排渲染

**字幕/旁白：**
> 漫画翻译的流程：截图后自动检测气泡区域，OCR 识别气泡里的文字，翻译后用竖排文字覆盖在原位置。
>
> 整个过程全自动，翻到新的一页，点击一下就能翻译。

**重点展示：**
- 漫画翻译按钮位置
- 翻译过程的完整流程（检测 → OCR → 翻译 → 渲染）
- 竖排文字渲染效果

### 3.2 检测和 OCR 引擎（20s）

**演示：** 普通模式循环切换 → 高级模式自由搭配

**字幕/旁白：**
> 星译内置 PP-OCRv5 引擎，不需要下载就能用，支持中日英混合识别。
>
> 普通模式下，引擎自动循环切换 — 适合不想折腾的用户。
>
> 高级模式可以自由搭配检测器和识别器。比如用 RT-DETR-V2 检测气泡，用 manga-ocr 识别竖排日文。
>
> 韩文、俄文识别模型可以按需下载。

**重点展示：**
- 普通模式的切换菜单
- 高级模式的检测器 + 识别器选择
- 不同引擎组合翻译同一页面的效果对比

### 3.3 增量渲染（15s）

**演示：** 一个多气泡页面 → 开启增量渲染 → 首批气泡先翻译显示 → 第二批接着显示

**字幕/旁白：**
> 遇到气泡很多的页面，普通模式要等全部翻译完才能看到结果。
>
> 开启增量渲染后，气泡分批处理 — 第一批翻译完立即显示，不用干等。
>
> 对于 10 个以上气泡的页面，体验提升非常明显。

**重点展示：**
- 关闭增量渲染时的等待时间
- 开启增量渲染后首批快速出现的过程

### 3.4 自动翻页翻译（15s）

**演示：** 开启自动翻译 → 连续翻页 → 每页停稳后自动翻译

**字幕/旁白：**
> 开启自动翻译后，连续翻页会自动检测页面变化。停稳后大约 1 秒自动触发翻译。
>
> 如果想立即翻译，点击悬浮球跳过等待。
>
> 翻过的页面有缓存，再次打开秒显示，左上角会显示闪电标识。

**重点展示：**
- 连续翻页时自动触发的过程
- 缓存命中的 ⚡ 标识和刷新按钮

## 拍摄要点

### 需要准备的素材
1. **游戏画面：** 一个日文剧情游戏（如 Galgame），展示游戏翻译全流程
2. **漫画画面：** 一个日文漫画 App（如漫画天堂），气泡多的页面效果更好
3. **多 API 账号：** 至少准备必应（免费）、DeepL、一个 OpenAI 兼容 API，用于对比演示
4. **模型下载：** 提前下载好 manga-ocr，方便演示高级模式

### 画面录制建议
- 用 scrcpy 或 Android 自带录屏
- 游戏翻译录制时，悬浮球和翻译结果要清晰可见
- 漫画翻译录制时，注意展示检测框和渲染结果的对比
- 每个功能切换时用剪辑过渡，不要有空白等待

### 字幕建议
- 中文字幕 + 关键术语英文标注
- 每个功能标题用大字显示
- 重要操作用箭头或高亮标注
